修仙自动化 · 账号与功能

登录自己的 Telegram 账号，勾选每个账号要跑的功能，最后点「保存并应用」生成并安装定时任务。

1. 游戏群

还没填真实的游戏群：现在是仓库占位值，指令发不出去。

2. 新增账号

  1. 在 my.telegram.org → API development tools 建一个应用，拿到 api_id 和 api_hash。
  2. 填下面三项，点「发送验证码」；Telegram 会把验证码发到这个账号。
  3. 填验证码（开了两步验证再填密码）点「登录」：账号 id 和用户名自动读取。

3. 账号与功能

还没有账号，先在上面登录一个。

4. 通知（可选）

日报和战报通过 Hermes 的 hermes send 发出；不填就不发，自动化照常跑。

5. 保存并应用

按上面的配置生成任务并装到本机；改了功能后都要再点一次。没勾的、已移除的任务会被卸掉。
