# Reference repositories

These independent repositories are kept here for source comparison:

- `upstream-xiuxian-mian/`: Xiuxian upstream source and its original tests.
- `xianxia-companion/`: companion application source and development tools.

Both retain their own `.git` directory and working tree. Their former workspace
paths are compatibility symlinks. Run their tests from their own repository, not
as part of the production XIUXIAN test discovery.
