# 账号数据与 Git 边界

仓库只保存示例账号、示例角色及测试数据。账号标识、用户名、角色映射、群组目标、机器路径
均已替换；示例值不能直接用于实际发送。真实凭证、session、状态和运行记录只保存在私有运行环境。

## 开发与发布

只在脱敏源码副本中提交修改。提交前运行 `python3 scripts/privacy_guard.py --all-history`；仓库 CI
也会执行此检查。可把私有替换映射保存到 `.git/privacy-original-values.json`（权限 600），
或通过 `XIUXIAN_PRIVACY_MAP` 指定仓库外文件，增加对原始值的精确检查。检查不会打印匹配值。

检查映射格式为 `{"真实值": "仓库示例值"}`，文件不得提交。准备部署源码需要另一份反向映射，
格式为 `{"仓库示例值": "真实值"}`；一个示例值对应一个确定的真实值。运行：

```sh
python3 scripts/materialize_private_checkout.py \
  --private-map /private/location/runtime-values.json \
  --output /private/location/new-runtime-source
```

输出必须是源码副本以外的新目录。该命令只生成私有源码，不复制凭证、不启动任务、不覆盖线上。
核对目标账号、会话和差异后，使用现有发布流程更新代码，保留原状态写入者和调度。
私有源码副本禁止提交和推送。VPS 已有真实配置仍由运行环境持有。

## 历史清理

2026-10-16 清理了全部可写分支与标签的历史，移除了 `.maintenance/` 和真实收益报告目录。
提交元数据使用通用维护者身份。此次维护没有把示例账号部署到生产。

旧 clone、bundle 和工作树仍可能持有原始数据。需要继续开发时重新克隆清理后的仓库，
不要把旧历史合并回来。生产运行目录保留私有业务文件，并禁止向源码仓库提交或推送。
私有恢复备份只用于事故恢复，不得推送到任何远程。

GitHub 可能保留旧 SHA 的缓存页面；彻底清除服务端缓存需要仓库所有者联系 GitHub Support。
删除仓库中的历史也不能撤回他人已保存的副本。
