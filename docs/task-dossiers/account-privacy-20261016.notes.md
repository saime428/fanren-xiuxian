# 六账号仓库脱敏

目标：清除六个账号在源码、文件名、分支名及 Git 历史中的真实身份信息，保留线上自动化。

处理：重写所有可写分支与标签；账号、角色、群组目标及个人机器路径改用示例；移除真实运行
记录与收益报告；提交作者改为通用身份。私有恢复备份与映射不进入源码仓库。

边界：VPS 运行文件、会话、凭证、业务状态与调度保持私有，未向线上部署示例值。
开发在脱敏副本完成；生产运行目录禁止提交与推送，避免重新引入旧历史。

验证：扫描全部 Git 对象与引用的原始值，运行离线测试及新增隐私边界测试，并重新获取远程历史复核。
最终验收计数由本次维护的私有回执保存；本说明不包含账号映射、凭证或原始日志。

限制：服务端旧 SHA 缓存与外部副本不受 Git 强制推送控制，详见 [隐私流程](../privacy.md)。
